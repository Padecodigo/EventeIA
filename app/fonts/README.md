# Fontes self-hosted

Arquivos woff2 (subset latin, variáveis no eixo `wght`) baixados do Google Fonts e
carregados via `next/font/local` — o build não depende de rede.
Todas as famílias (Fraunces, Figtree, Outfit, DM Sans, Bricolage Grotesque, Manrope)
são licenciadas sob a SIL Open Font License 1.1 (ver `OFL.txt`; copyright dos respectivos autores).
